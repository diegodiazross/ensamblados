# Ensamblados 

En este proyecto examinamos una breve taxonomía de los métodos de ensamblados los cuales se componen de 4 clases principales y para cada caso se realizará un ejemplo práctico (1 notebook por cada clase).
Este proyecto fue desarrollado en visual studio code utilizando utilizando WSL y Python 3.12.3.  Recomiendo crear un entorno virtual e instalar las dependencias (requirements.txt).
